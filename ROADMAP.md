# Roadmap

Продуктовые требования: docs/SPEC.md (baseline-центричный UX, научная корректность). Навигация: Главная · Поиск · Спектр · Карта · История.

- [x] 0. Обзор существующих реализаций (Open-RadiaCode-Android, cdump/radiacode и др.) → ADR 001: стек и ядро протокола
- [x] 0.1. Порт протокола (:protocol, 36 тестов) + скаффолд :app
- [ ] 1. Спайк: BLE-подключение к RadiaCode 110, чтение real-time данных — критерий: ≤1 разрыва за 10 минут; заодно проверить единицы dose_rate (cdump #56) и дрейф base_time (#63)
- [~] 2. Главная: сделано — дизайн-система «8-bit» в Compose (темы CRT/DMG, Pixelify Sans, пиксельные компоненты и график), онбординг с подключением, Монитор (доза, CPS, доза за день, часовой график с порогом, честное устаревание, статус соединения). Осталось: статус пока по фиксированному порогу — baseline-полоса и формулировки «относительно привычного» ждут baseline-движок (этап 3)
- [x] 3. Baseline-движок: взвешенная перцентильная полоса P10–P90 по местам с отсечкой всплесков и активацией после 3 ч (ADR 002); статусы «Обычный фон / Выше обычного / Уровень радиации изменился» = величина И длительность; места с ручным выбором на Мониторе, полоса на графике, события отклонений в журнале
- [~] 4. Поиск: сделано — полноэкранный CPS-режим, замер локального фона (45 с), ±2σ-полоса, LED-индикатор, 60-с график. Осталось: звук/вибро от интенсивности
- [ ] 5. Спектр: накопление, лог/лин, наложение и вычитание фона, осторожные подсказки изотопов; спектрограмма — в Advanced
- [ ] 6. Карта: трек с точками по дозе/CPS, автометки устойчивых превышений
- [~] 7. История и Настройки: сделано — сессии измерений (открытие/закрытие по подключению, схема v2) со сводками мин/ср/макс/CPS/доза и бейджами спектра/трека, накопленная доза сегодня/7д/30д, события отклонений с контекстом «обычно здесь X», деталка сессии с графиком всего периода; Настройки (шестерёнка с Монитора): тревоги Обычная/Высокая/Своя (уровень+baseline+длительность), управление местами, экран прибора (серийник/прошивка/батарея/температура/поток), единицы мкЗв/ч⇄мкР/ч (display-only), лицензии. Осталось: Advanced-тревоги по CPS и накопленной дозе, экспорт данных
