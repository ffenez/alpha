# Roadmap

- [ ] 0. Обзор существующих реализаций (Open-RadiaCode-Android, cdump/radiacode и др.) → ADR 001: стек и ядро протокола
- [ ] 1. Спайк: BLE-подключение к RadiaCode 110, чтение real-time данных (доза, cps) — критерий: стабильные показания ≥10 минут без разрыва
- [ ] 2. Ядро протокола + живой дашборд (доза, счёт, аккумулятор устройства, статус связи)
- [ ] 3. Спектр: приём, энергетическая калибровка, отображение
- [ ] 4. Журнал измерений: локальное хранение, графики истории
- [ ] 5. Экспорт (открытые форматы), тревоги/пороги, полировка UI
