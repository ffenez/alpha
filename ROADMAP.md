# Roadmap

Продуктовые требования: docs/SPEC.md (baseline-центричный UX, научная корректность). Научная спецификация и порядок работ: `docs/spec/scientific-instruction.md` + `docs/plan/scientific-program.md` (блоки 10+). Навигация: Главная · Поиск · Спектр · Карта · История.

Главная: сделано — дизайн-система «Научный терминал» в Compose (вариант F: IBM Plex Sans/Mono, тёмная+светлая темы, карточки/чипы/segmented, графики с осями и погрешностями; заменила отклонённый после полевой проверки «8-bit» — пиксельный шрифт нечитаем), онбординг с подключением, Монитор (доза ±err, счёт ±σ, тренд/ч, доза за день, часовой график с полосой baseline и линией L1, честное устаревание, статус соединения; полноэкранный живой график по тапу на карточке — периоды 15м/1ч/6ч/24ч/7д, pan/pinch по времени, live-follow с чипом «⌖ сейчас», statgrid видимого окна). Осталось: статус пока по фиксированному порогу до активации baseline — закрыто этапом 3

Поиск: сделано — полноэкранный CPS-режим, замер локального фона (45 с), ±2σ-полоса, LED-индикатор, 60-с график, звук/вибро от интенсивности (Geiger-клики с Пуассоновыми интервалами по CPS, σ-ступенчатые вибро-пульсы; тумблеры на экране, уважение DND). ПОЛЕВАЯ ПРАВКА 2026-08-10 (звук и вибро не работали совсем): клики переведены с USAGE_ASSISTANCE_SONIFICATION (=STREAM_SYSTEM, глохнет в режиме «вибрация/без звука») на поток медиа, отказ в аудиофокусе больше не глушит навсегда, буфер AudioTrack считается в байтах, проверяется STATE_INITIALIZED; кадровый цикл вынесен в чистый ClickEngine с JVM-тестами; под тумблерами — честная строка с реальной причиной тишины, а в Настройках новый раздел «Проверка» (кнопки «Проверить звук» и «Проверить вибрацию» мимо всех гейтов с конкретным ответом). Опрос DATA_BUF на этом экране 2 Гц — меньше задержка подбора (не больше измерений). Осталось: подтверждение на устройстве, что звук/вибро слышны
- [~] 5. Спектр: сделано — накопление (опрос спектра «с последнего сброса» раз в 5 с параллельно 1 Гц DATA_BUF, автоснимки 1/мин + [СОХРАНИТЬ] с событием журнала), гистограмма счёт/кэВ с лог/лин-шкалой, декадами и энергетической осью, зум окном энергий (кнопки + щипок/сдвиг), [СБРОС] с подтверждением, запись опорного фона + наложение + «минус фон» с нормировкой по времени накопления, сглаживание только на отображении, осторожные подсказки изотопов (библиотека 13 линий, пики по Poisson-SNR, уверенность максимум «средняя», спокойная пометка природного фона K-40/радоновой и ториевой цепочек), честные состояния (нет связи / неподдержанный SpecFormatVersion / <60 с накопления). Осталось: спектрограмма — в Advanced; проверка на реальном приборе (форматы v0/v1, длительность чтения спектра)
- [~] 6. Карта: сделано — osmdroid 6.1.20 + растровые тайлы OpenStreetMap без ключей (ADR 003: MapLibre GL Native давал серый экран на устройстве дважды — Vulkan и OpenGL-пакеты; osmdroid рисует Canvas-ом, своей GPU-поверхности нет). Отличительный User-Agent по политике тайлов OSM, кэш 512 МБ (посещённые районы работают офлайн, bulk-предзагрузки сознательно нет), тёмная тема — матрица «инверсия + поворот тона 180°», светлая — без фильтра, трек с точками по дозе/CPS (янтарная рампа с квантильными порогами P25/P50/P75 видимого трека, легенда мин/макс, downsampling до 2000 отрисованных точек — сводки всегда по полному ряду), запись маршрута с вкладки (существующий трекинг foreground service; честное объяснение геолокации, фоновая локация не запрашивается), оверлей-чипы записи и дистанции, сводка «Мой маршрут», метки устойчивых превышений с карточкой (доза, CPS из samples, «обычно здесь X», «показания устойчивы N с»), карточка точки (доза · CPS · время), честные состояния (нет разрешения / GPS выключен / пусто — обучение первому действию) и статус тайлов на экране («загружаются / готово / ошибка сети» + подсказка про разрешение «Сеть» в GrapheneOS, если не пришло ни одного тайла), просмотр трека прошлой сессии из Истории («трек · на карте»). Осталось: проверка на реальном устройстве (рисуется ли карта, GPS-трек, офлайн-кэш тайлов)
- [~] 7. История и Настройки: сделано — сессии измерений (открытие/закрытие по подключению, схема v2) со сводками мин/ср/макс/CPS/доза и бейджами спектра/трека, накопленная доза сегодня/7д/30д, события отклонений с контекстом «обычно здесь X», деталка сессии с графиком всего периода; Настройки (шестерёнка с Монитора): тревоги Обычная/Высокая/Своя (уровень+baseline+длительность), управление местами, экран прибора (серийник/прошивка/батарея/температура/поток), единицы мкЗв/ч⇄мкР/ч (display-only), лицензии, системное уведомление тревоги (канал «Тревога» со звуком/вибро, раз на эпизод) со строкой настройки, секция «Интерфейс» (порядок/видимость вкладок меню с защитой «Главная + минимум одна», тумблеры блоков Монитора, сброс к дефолту). - [~] 10. Научная программа, этап 1 (спец §3, §4, §17, §20, §21): сделано — **профили вместо «мест»** (`profiles`: имя, иконка, вложенность на один уровень «Дом / Спальня», архив, тумблеры «включать автоматически» и «учить обычный фон», роли user/transit/no_place; пресеты Дом · Офис · Дача · Родители · В пути · Без места; Room v5→v6 переносит места в профили, сохраняя id и привязку измерений — колонки `placeId` осознанно оставлены под старым именем, т.к. Осталось: полевая проверка на устройстве (узнаётся ли домашний Wi-Fi, срабатывает ли grace при выходе из дома, не мигает ли профиль на границе сети)
