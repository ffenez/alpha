# Переработка настроек: структура и комбинируемый отклик

## Цель

Сделать настройки:
- понятными без чтения длинных пояснений;
- сгруппированными по задачам пользователя;
- единообразными;
- расширяемыми;
- допускающими комбинации вроде **щёлчки + вибрация одновременно**.

## 1. Главная структура

На верхнем уровне лучше использовать такие категории:

- **Измерение**
  - Профили и фон
  - Пороги и тревоги
- **Поиск**
  - Отклик
  - Точка отсчёта
- **Спектр**
  - Отображение
  - Спектрограмма
  - Энергетические диапазоны
- **Карта**
  - Цвет следа
  - Запись маршрута
- **Интерфейс**
  - Язык и единицы
  - Оформление
  - Главная
  - Масштаб
- **Прибор**
  - Подключение
  - Звук и вибрация прибора
  - Калибровка
- **Данные**
  - История и хранение
  - Резервная копия
  - Импорт / экспорт
- **Диагностика**
- **О приложении**

---

## 2. Экран «Отклик» сейчас логически ограничен

Сейчас используется взаимоисключающий выбор:

`нет | клики | тон | вибро`

Но пользователь может захотеть:
- щелчки + вибрацию;
- тон + вибрацию;
- все три;
- только один способ;
- ничего.

Поэтому здесь нужен не segmented control, а **независимые переключатели**.

### Сделать так

```text
ОТКЛИК В ПОИСКЕ

Щелчки                         [вкл]
Каждый зарегистрированный импульс

Тон по энергии                 [выкл]
Высота тона зависит от энергии импульса

Вибрация                       [вкл]
Тактильный отклик при импульсах
```

Если всё выключено — это и есть режим «нет». Отдельный пункт `нет` не нужен.

---

## 3. Модель данных

Не хранить:

```text
searchFeedbackMode = NONE | CLICKS | TONE | VIBRATION
```

Потому что это запрещает комбинации.

Нужно:

```text
searchFeedback.clicksEnabled
searchFeedback.energyToneEnabled
searchFeedback.vibrationEnabled
```

Это источник истины.

При желании сверху можно добавить UI-пресеты:

```text
Тихо | Обычный | Тактильный | Свой
```

где:
- Тихо = всё выключено;
- Обычный = щелчки;
- Тактильный = щелчки + вибрация;
- Свой = пользовательская комбинация.

Но пресет не должен заменять независимые настройки.

---

## 4. Тон и вибрация — с дочерними параметрами

Если `Тон по энергии` включён:

```text
Тон по энергии                 [вкл]
  Диапазон высоты тона          >
  Громкость                     >
```

Если выключен — вложенные параметры скрыть.

Для вибрации:

```text
Вибрация                       [вкл]
  Интенсивность              средняя >
```

Не перегружать экран дополнительными настройками до появления реальной потребности.

---

## 5. Поиск и тревога должны быть разделены

`Отклик в Поиске` — постоянная обратная связь.

`Тревога` — отдельное событие превышения порога.

Экран:

```text
ПОИСК
Щелчки                         [вкл]
Тон по энергии                 [выкл]
Вибрация                       [вкл]

ТРЕВОГА
Звук и вибрация тревоги          >
```

Внутри тревоги:

```text
Звук                           [вкл]
Вибрация                       [вкл]
Мелодия                        >
Повтор                         >
```

---

## 6. «Интерфейс» нужно разбить

Сейчас там смешаны язык, тема, единицы, масштаб, цвет, Главная, навигация и другие параметры.

Оставить на первом экране:

```text
Язык и единицы                 >
Оформление                     >
Главная                        >
Масштаб                        >
```

### Язык и единицы

```text
Язык                     Русский >
Единицы                  мкЗв/ч  >
```

### Оформление

```text
Тема                     Системная >
Стиль                    Научный   >
Пояснения                      [выкл]
Цвет значения по фону          [вкл]
```

При `Пояснения = выкл` длинные серые методические тексты не показывать. Справка остаётся через `i` / `?`.

---

## 7. Масштаб

На основном экране не нужны огромные ползунки.

```text
Текст        110 %    >
Элементы     110 %    >
Вернуть 100 %
```

Сам slider показывать уже внутри выбранного пункта.

---

## 8. Настройка Главной

Отдельный экран:

```text
ГЛАВНАЯ

Всегда:
• текущее значение
• статус
• график мощности дозы

Дополнительно:
Тренд                         [вкл]
Доза сегодня                  [вкл]
Скорость счёта                [вкл]
Жёсткость                     [выкл]
```

Если пользователь может менять порядок блоков — использовать drag handle только здесь.

---

## 9. Нижняя навигация

При четырёх основных вкладках:
- Главная
- Спектр
- Карта
- История

я бы не давал свободно менять их порядок. Это добавляет сложность без заметной пользы.

Если настройка всё же нужна — разрешить скрывать только второстепенные вкладки, но не разрушать основной каркас.

---

## 10. Прибор

Сделать компактнее:

```text
RADIACODE-110
● Подключено
84 % · 23 °C · 1 Гц

Подключение                    >
После перезапуска              [вкл]

СИГНАЛЫ ПРИБОРА
Звук прибора                   [выкл]
Вибрация прибора               [выкл]

СПЕКТР
Спектральные диапазоны       3 >
Проверка калибровки            >
```

### Важно

Для обычного boolean не использовать `Выкл | Вкл` как segmented control.

Использовать switch:

```text
Звук прибора                   [вкл]
Вибрация прибора               [выкл]
```

Если реальное состояние прибора нельзя прочитать:

```text
Звук прибора            неизвестно >
```

После первой команды состояние можно считать известным только если это подтверждается протоколом.

---

## 11. Спектральные диапазоны

На экране прибора не показывать техническую строку:

`100–300 · 300–700 · 700–1500`

Достаточно:

```text
Спектральные диапазоны       3 >
```

Сами границы — внутри отдельного экрана.

---

## 12. Калибровка

Оставить нейтральное название:

`Проверка спектральной калибровки`

Потому что это не обещает, что приложение автоматически изменяет коэффициенты прибора.

Внутри:

```text
Энергетическая шкала
Статус: в норме / требует проверки

Контрольные линии:
K-40 ...
...

Проверить сейчас
```

Кнопку `Калибровать` показывать только если приложение действительно умеет корректно менять коэффициенты.

---

## 13. Данные и резервные копии

Компактная структура:

```text
РЕЗЕРВНАЯ КОПИЯ
Создать копию                   >
Восстановить                    >

ХРАНЕНИЕ
Детализация истории       Всё >
Размер данных             37,4 МБ

ПЕРЕНОС
Экспорт                         >
Импорт                          >
```

Длинное объяснение про удаление посекундных данных перенести в справку или показывать только при включённых пояснениях.

---

## 14. Экспорт

В отдельном экране:

```text
Полная резервная копия
История измерений
Сессии
Маршруты
Спектры
Эксперименты
Настройки
```

Форматы по смыслу:
- HTML — красивый человекочитаемый отчёт;
- CSV — таблицы;
- XML / N42 — спектры, где применимо.

## 15. Диагностика

Сейчас экран перегружен объясняющим текстом.

Сделать:

```text
СПЕКТРОГРАММА
Запись в фоне             30 с >
Очистить спектрограмму          >

ОТЛАДКА
Отчёт о состоянии               [вкл]
Создать архив отладки           >
```

Поле `Что не работает` показывать после нажатия `Создать архив отладки`, а не держать пустым постоянно.

---

## 16. Правило выбора компонента

### Switch
Независимое да/нет:
- щелчки;
- вибрация;
- пояснения;
- тренд;
- отчёт состояния.

### Segmented control
Только взаимоисключающие режимы:
- системная / тёмная / светлая;
- 30 дней / 90 дней / всё;
- линейная / логарифмическая.

### Строка с `>`
Если есть отдельный вложенный экран.

### Slider
Для непрерывной величины:
- масштаб;
- громкость;
- интенсивность.

### Radio list
Для одного выбора из большого списка.

## 17. Итоговый экран «Отклик»

```text
‹ Отклик

ПОИСК

Щелчки                         ●
Тон по энергии                 ○
Вибрация                       ●

ТРЕВОГА

Звук и вибрация тревоги         ›

ПРИБОР

Звук прибора                   ○
Вибрация прибора               ○
```

Это проще, логичнее и позволяет включить одновременно, например, **щёлчки + вибрацию**.

---

## 18. Общий UI-контракт на будущее

Для каждой новой настройки сначала определить:

1. Независимое `вкл/выкл` → switch.
2. Один выбор из 2–4 режимов → segmented control.
3. Большой список → отдельный экран.
4. Числовая величина → slider/stepper.
5. Есть дочерние параметры → строка с `>`.
6. Техническое объяснение → справка / `i` / режим пояснений.

Не создавать новый уникальный UI-паттерн, если уже существует подходящий стандартный компонент.

---

## Acceptance criteria

- Можно одновременно включить **щёлчки + вибрацию**.
- Можно включить **тон + вибрацию**.
- Можно включить все три режима.
- Выключение всех трёх эквивалентно `нет`.
- Поисковый отклик не меняет настройки тревоги.
- Настройки приложения не меняют аппаратные сигналы прибора без отдельного явного действия.
- Boolean-настройки отображаются switch.
- Длинные пояснения скрываются при `Пояснения = выкл`.
- Все вложенные экраны используют одинаковую кнопку назад/AppBar.
- Новые настройки в будущем используют существующие категории и компоненты.
