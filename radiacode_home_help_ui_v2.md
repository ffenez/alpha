# RadiaCode — Главная: перенос пояснений в «Справку» и новый UI справки

## Цель

Очистить Главную от обучающего и диагностического текста, который не нужен для постоянного наблюдения, и перенести его в отдельную **«Справку»**.

Текущую кнопку/окно **«Информация»** переименовать в:

```text
Справка
```

Справка должна быть понятной обычному человеку, но при этом сохранять научную точность и технические данные для продвинутого пользователя.

## 1. Что убрать с Главной

Сейчас в основной карточке есть:

```text
● Идут измерения
изучаю обычный фон — 0,9 ч из 3
```

Оставить на Главной только короткий статус:

```text
● Идут измерения
```

Строку:

```text
изучаю обычный фон — 0,9 ч из 3
```

убрать с Главной и перенести в `Справку`.

Это состояние фоновой модели, а не основное текущее измерение.

## 2. Главная после упрощения

```text
МОЩНОСТЬ ДОЗЫ

0,16

┌──────────┬──────────┬──────────┐
│ ФОН      │ ДИНАМИКА │ ДОЗА     │
│ —        │ +0,007 ↗ │ 0,19     │
└──────────┴──────────┴──────────┘

● Идут измерения
```

Не показывать здесь постоянно:
- ход обучения фона;
- исключённые интервалы;
- причины отсутствия фона;
- параметры алгоритма.

## 3. «Информация» → «Справка»

Во всём приложении это окно переименовать в:

```text
Справка
```

Потому что оно объясняет не только данные, но и:
- что происходит;
- почему ещё нет фона;
- как выполняется сравнение;
- какие измерения учитываются;
- какие параметры использует алгоритм.

## 4. Новая структура справки

Справка не должна сразу открываться длинным техническим отчётом.

Первый уровень должен отвечать только на три вопроса:

1. Что происходит сейчас?
2. Есть ли подтверждённое отклонение?
3. Почему приложение пришло к этому выводу?

Пример:

```text
Справка

● Идут измерения

СЕЙЧАС
0,16 мкЗв/ч

ФОН ЭТОГО МЕСТА
0,9 ч из 3 ч
[█████░░░░░░░]

СРАВНЕНИЕ
Недостаточно данных

ИСКЛЮЧЕНО ИЗ ФОНА
12 мин · Поиск или эксперимент    >

Как определяется отклонение       >
Технические параметры             >
```

## 5. «Фон этого места»

Убрать формулировку:

```text
изучаю обычный фон
```

Она звучит как текст внутреннего алгоритма.

Использовать:

```text
Фон этого места
0,9 ч из 3 ч
```

или:

```text
Фоновый профиль
собрано 0,9 ч из 3 ч
```

Предпочтительно первое.

Добавить progress indicator.

Если `Пояснения на экранах = OFF`, не показывать длинное объяснение под progress.

## 6. «Недостаточно данных»

Сейчас:

```text
Сейчас  Недостаточно данных
```

Это выглядит как будто `Недостаточно данных` — значение измерения.

Заменить на отдельный блок:

```text
СРАВНЕНИЕ С ФОНОМ

Недостаточно данных
```

Когда фон готов:

```text
СРАВНЕНИЕ С ФОНОМ

В обычном диапазоне
```

или реальный статус алгоритма.

## 7. Спектральное сравнение

Сейчас:

```text
СПЕКТРАЛЬНОЕ СРАВНЕНИЕ
Сейчас не оценивалось
```

Не показывать отдельным крупным блоком, если оно не участвовало в текущем выводе.

Сделать disclosure row:

```text
Спектральное сравнение          >
```

По тапу:

```text
Спектральное сравнение пока не выполнялось.
```

Если есть результат — показать реальный результат.

## 8. Исключённые измерения

Сейчас блок повторяет одну и ту же информацию:

```text
Почему сейчас идёт Поиск или эксперимент
Не пошло в обычный фон 12 мин
идёт Поиск или эксперимент 12 мин
```

Сократить до:

```text
ИСКЛЮЧЕНО ИЗ ФОНА
12 мин · Поиск или эксперимент    >
```

По тапу:

```text
Не вошло в фон: 12 мин

Причина:
Поиск или эксперимент
```

## 9. Параметры определения отклонения

Не показывать их сразу.

Сделать disclosure:

```text
Как определяется отклонение     >
```

Первый уровень:

```text
Отклонение отмечается, если уровень достаточно сильно
выше обычного для этого места и держится не менее 2 минут.
```

Ниже:

```text
Технические параметры           >
```

И только там:

```text
Абсолютный порог L1        0,30 мкЗв/ч
Относительный порог        2 × P90 фона
Минимальная длительность   2 мин
Возврат                    ниже порога
Пауза после события        30 мин
```

## 10. Убрать кнопки «Скрыть ...»

Не использовать:

```text
Скрыть методику и расчёты
Скрыть технические параметры
```

По умолчанию технические данные должны быть закрыты.

Использовать обычные строки:

```text
Методика и расчёты         >
Технические параметры      >
```

или accordion с chevron.

## 11. При выключенных пояснениях

Основной уровень справки должен оставаться коротким:

```text
Справка

● Идут измерения

Сейчас
0,16 мкЗв/ч

Фон этого места
0,9 ч из 3 ч

Сравнение
Недостаточно данных

Исключено из фона
12 мин

Как определяется отклонение >
Технические параметры       >
```

То есть даже `Справка` не должна превращаться в книгу.

## 12. При включённых пояснениях

Можно добавить короткие объяснения, например:

```text
Приложение собирает обычные измерения этого места,
чтобы отличать естественные колебания от изменений.
```

Но не длинные абзацы на первом уровне.

## 13. Два уровня справки

### Уровень 1 — пользовательский
- текущий статус;
- текущая мощность дозы;
- прогресс фона;
- статус сравнения;
- исключённое время.

### Уровень 2 — технический
- L1;
- P90;
- относительный критерий;
- минимальная длительность;
- исключение после события;
- спектральная статистика;
- подробная методика.

Не смешивать их на одном экране.

## 14. Как открывать

Предпочтительно:
- тап по `● Идут измерения`;
- либо icon `i` / `?` в верхней части Главной.

Семантически действие называется `Справка`.

## 15. Container

Предпочтительно использовать:

```text
ModalBottomSheet
```

на 70–85 % высоты.

Плюсы:
- естественный скролл;
- можно закрыть свайпом;
- disclosure-секции выглядят нативно;
- это информационный экран, а не confirmation dialog.

Если архитектура уже привязана к dialog, можно оставить dialog, но переработать иерархию.

## 16. Убрать кнопку «Понятно»

Справка не требует подтверждения.

Убрать большую кнопку:

```text
Понятно
```

Закрытие:
- `×`;
- swipe-down;
- системный Back.

## 18. Acceptance criteria

Готово, если:
- `изучаю обычный фон — 0,9 ч из 3` убрано с Главной;
- на Главной остаётся только короткий статус `● Идут измерения`;
- `Информация` переименована в `Справка`;
- прогресс фона отображается внутри справки;
- фраза `изучаю обычный фон` больше не используется;
- `Недостаточно данных` оформлено как статус сравнения;
- спектральное сравнение не занимает постоянный крупный блок, если оно не выполнялось;
- исключённые измерения сведены к одной компактной строке;
- повтор `Поиск или эксперимент` убран;
- параметры алгоритма скрыты по умолчанию;
- нет кнопок `Скрыть методику...` и `Скрыть технические параметры`;
- нет обязательной кнопки `Понятно`;
- при выключенных пояснениях справка остаётся компактной;
- подробные технические данные доступны на втором уровне;
- UI выглядит как современная справка измерительного приложения, а не диагностический отчёт.
