# Картинки README

Сюда кладут скриншоты для `README.md` и `README_RU.md`.

Перед добавлением каждой картинки проверяется, что на ней нет:

- серийного номера прибора (экран «Прибор», технические данные снимка);
- карты с реальным адресом и следа маршрута;
- имён профилей мест, если они личные;
- уведомлений и содержимого шторки;
- отладочных наложений;
- EXIF с координатами, моделью телефона и датой.

Проверка EXIF одной командой:

```
exiftool -GPS* -Make -Model -Software -DateTimeOriginal docs/images/*.png
```

Скриншоты в этом каталоге отслеживаются git (исключение в `.gitignore`),
поэтому непроверенная картинка попадёт в публичную историю. Ссылки на
конкретные файлы и результат проверки — в рабочей карте проверок.
