# Дизайн-язык «Зиверт» v1

Рабочее имя приложения — «Зиверт». Мокап ключевых экранов: артефакт «Зиверт — дизайн RadiaCode-приложения» (claude.ai, версия design-v1). Направление: полевой измерительный прибор — тёмная тема основная, моноширинная цифирь, один акцент со значением «требует внимания».

## Палитра

Тёмная (основная): грунт `#0E1413`, поверхность `#161D1B`, поверхность-2 `#1C2523`, линия `#243029`, текст `#E6EDE9`, вторичный `#93A39C`, приглушённый `#5F6E67`.
Светлая: грунт `#F1F5F2`, поверхность `#FFFFFF`, текст `#1B2620`, вторичный `#61726A`, линия `#DCE4DE`.

Семантика (тёмная / светлая):
- Внимание (акцент): `#E8A33D` / `#A56410` — только «требует внимания сейчас» (запись, превышение). Не украшение.
- Норма: `#55C08B` / `#1E7A50`. Тревога: `#E86A5E` / `#BC3E33`.
- Данные на графиках (не статус): бирюза `#22A0B6` / `#177E92`.
- Рампа дозы на карте (магнитуда, один тон): `#E8CB93 → #C4831E → #8F5312 → #5C300A`.

Chart-палитра `#22A0B6, #C4831E, #33A268, #D14538` прошла dataviz-валидатор в обоих режимах (светлота, хрома, CVD, контраст).

## Типографика

- Числа и показания: IBM Plex Mono (OFL, бандлится в APK), `tabular-nums`; главное число дашборда 54sp/600.
- UI-текст: системный (Roboto). Подписи-лейблы: 11.5sp, uppercase, letter-spacing 0.06em.

## Правила

- Статус никогда не только цветом: рядом слово или иконка.
- Сетка 4dp; радиусы карточек 14/18dp; цели нажатия ≥44dp; частые действия — в нижней трети.
- Обязательные состояния каждого экрана: пусто (учит первому действию), поиск устройства, связь потеряна/переподключение, длинные значения.
- Единицы не отрываются от числа; конвертация единиц — только явной настройкой, везде одинаково.
- Навигация: нижняя панель Монитор / Спектр / Карта / Журнал.
