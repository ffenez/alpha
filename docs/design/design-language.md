# Дизайн-язык «alpha» — выбран вариант D «8-bit» (гибрид)

Мокап: артефакт «Зиверт — вариант D „8-bit“» (claude.ai, версия design-d-v2-hybrid). История выбора: A «Полевой прибор» и C «Контекст» отклонены пользователем в пользу 8-bit; B снят. Информационная модель — из docs/SPEC.md (baseline, статусы «обычно/выше обычного», Поиск, осторожные изотопы, честное устаревание).

## Принцип

Ретро-консоль как каркас: пиксельная сетка, чанки-рамки, CRT-фосфор. **Гибрид**: экраны данных (Главная, Поиск, Спектр, Карта, История) — пиксельные; служебные экраны и длинные тексты (Настройки, объяснения, списки) — обычный системный шрифт внутри пиксельных рамок.

## Темы

CRT (тёмная, основная): грунт `#0B1406`, поверхность `#12200C`, поверхность-2 `#1A2C10`, рамка `#2C4A18`, текст `#C9EE9A`, фосфор-акцент `#9BE838` (глоу только у главного числа и статуса), вторичный `#7FA45C`, приглушённый `#557A38`.
DMG (светлая): стекло `#C4CFA1`, поверхность `#CDD8AC`, текст `#1E3009`, вторичный `#44622A`, рамка `#9AAA76`, акцент `#16260A`.

Семантика: статус «выше обычного» — янтарь `#E8B93D` (CRT) / `#8A6206` (DMG), ТОЛЬКО в тексте рядом со словами, в графики не попадает (не различим с жёлто-зелёным при дейтеранопии — валидатор ΔE 1.9). В графиках два цвета-метки: данные `#55A81E` / `#3F7A14`, тревога `#E05570` / `#B3263C` — пара прошла валидатор в обеих темах. Рампа дозы на карте (4 шага, светлее→темнее): `#C8E86A → #8BC91E → #4C7E14 → #24420C`.

## Типографика

- Pixelify Sans (OFL, бандлится; latin+cyrillic) — заголовки, числа, экраны данных; главное число 64sp/700.
- Системный Roboto — тела текста в Настройках, объяснения, юридические/длинные строки.
- Табличные цифры везде, где значения обновляются.

## Форма

- Радиусы 0; рамки 3dp; тени-чанки 5dp (сдвиг вправо-вниз, без размытия); выравнивание по пиксельной сетке.
- Графики рисуются в низком разрешении и масштабируются целыми кратными (Compose: Canvas в маленький IntSize + FilterQuality.None). Дизеринг (шахматный паттерн) вместо полутонов; baseline-полоса — дизеринг.
- CRT-оверлей: сканлайны + виньетка, только в тёмной теме, отключаемы.
- Анимации — стэп-функции (мигание курсора, LED-сегменты), уважать reduced-motion; измерения не сглаживать ради красоты.

## Информативность

Каждый экран данных несёт сводку: оси с подписями (время, шкала, декады лога), σ и мин/ср/макс у графика, «за сколько часов собран baseline», «обновлено N с назад», у сессий — число измерений, у карты — масштабная линейка и сводка трека. Статус никогда не только цветом — рядом слово или символ.
