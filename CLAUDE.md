# radiacode

Современное Android-приложение для дозиметра-спектрометра RadiaCode 110: подключение по BLE, живые показания, спектр, журнал. Замена официального приложения с упором на приватность и качество UI.

## Stack

- Kotlin, Jetpack Compose (Material 3), coroutines/Flow; minSdk 26
- BLE: Kable (Apache-2.0) + собственный порт протокола cdump/radiacode (MIT, атрибуция обязательна)
- Хранение: Room (SQLite)
- Карта: MapLibre GL Native + тайлы OpenFreeMap; геолокация — LocationManager (не Fused)

## Invariants

- Данные измерений и координаты не покидают устройство. Никакой телеметрии, аналитики, крэш-репортинга в сеть. Единственный разрешённый сетевой трафик — анонимная загрузка тайлов карты (с агрессивным кэшем; тайл-запросы не должны содержать ничего, кроме координат тайла).
- Никаких зависимостей от Google Play Services / Firebase — целевое устройство GrapheneOS без GMS.
- BLE-протокол RadiaCode реверс-инжинирен сообществом; собственный код протокола писать по документации/идеям, код копировать только из совместимых по лицензии источников с атрибуцией (GPL-код не копировать).
- Дозиметрические величины: хранить сырые значения и единицы (мкЗв/ч, cps), не терять точность при конвертации.

## Commands

- Сборка: `JAVA_HOME=/home/dev/.local/jdk ./gradlew :app:assembleDebug` (свежий APK автоматически копируется в `apk/app-debug.apk`)
- Тесты: `JAVA_HOME=/home/dev/.local/jdk ./gradlew test` (JVM-тесты :protocol и :app)
- Lint: `JAVA_HOME=/home/dev/.local/jdk ./gradlew :app:lintDebug`

## Key decisions

- Протокол — чистый Kotlin-порт cdump/radiacode; Open-RadiaCode-Android без лицензии — только идеи, не код (ADR 001)
- Один запрос в полёте, матчинг по эхо заголовка; канонический SPEC_ACCUM = 0x205
- Устройство держит одного BLE-клиента: сосуществование с официальным приложением невозможно, это ограничение UX
- Непрерывное измерение — foreground service + запрос исключения из battery optimization
- UI — дизайн-система «8-bit hybrid» (docs/design/design-language.md): токены в `app/.../ui/theme`, компоненты в `app/.../ui/components`; экраны тонкие, вся тестируемая логика UI — в `ui/logic` (чистый JVM)
- Baseline — взвешенная перцентильная полоса P10–P90 по минутным корзинам места (окно 14 дней, отсечка >3×медианы, активация после 3 ч); отклонение = величина И длительность (`PersistenceTracker`); движок чистый JVM в `app/.../baseline/` (ADR 002)
- Room v2 со схемами в `app/schemas` (миграции проверяются JVM-тестом на sqlite-jdbc без инструментации); сессии измерений не дублируют данные — сводки агрегируют `samples` по диапазону времени
- Единицы отображения мкЗв/ч⇄мкР/ч (×100) — только на выводе через `DoseFormat`, сырые значения неизменны
- Спектр: экран опрашивает спектр «с последнего сброса» раз в 5 с через тот же однозапросный клиент (перемежается с 1 Гц DATA_BUF; мост UI↔сервис — `SpectrumHub`); анализ пиков — чистый JVM в `app/.../analysis/`: локальный максимум сглаженного ряда + боковой континуум + Poisson-SNR при FWHM(E)=8%·√(662·E); подсказки изотопов всегда «возможное совпадение», уверенность максимум «средняя», «обнаружен» не пишется никогда
- Pixelify Sans бандлится с локальным cmap-патчем: в upstream-шрифте нет заглавных кириллических О (U+041E) и П (U+041F), добавлены маппинги на идентичные глифы O и Π (см. `app/src/main/assets/licenses/pixelify_sans_NOTICE.txt`); при обновлении шрифта патч переприменить
